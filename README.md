# Мои контакты (CustomAdapterDemo)

Учебное Android-приложение на Java с собственным адаптером `BaseAdapter`.

## Возможности
- начальная загрузка контактов из `app/src/main/assets/contacts.json`;
- добавление контакта с русским именем и номером телефона;
- выбор одного из пяти встроенных типов аватаров;
- выбор собственного изображения из галереи телефона (PNG, JPG и другие форматы изображений);
- сохранение добавленных контактов и выбранных фотографий после перезапуска приложения;
- сортировка по имени, номеру телефона и типу аватара;
- выделение выбранной записи и прокручиваемый список.

## Запуск
Откройте папку проекта в Android Studio, дождитесь синхронизации Gradle и запустите приложение на эмуляторе или устройстве.
